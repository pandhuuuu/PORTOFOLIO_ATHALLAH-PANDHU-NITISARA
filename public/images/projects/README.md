# Project Images

Simpan semua aset gambar/screenshot proyek Anda di folder ini.
Disarankan untuk membuat subfolder untuk masing-masing proyek agar terstruktur, contoh:
- `/public/images/projects/project1/`
- `/public/images/projects/project2/`

Format gambar yang direkomendasikan adalah **WebP** untuk ukuran file yang optimal.
